# 🛒 Amazon Clone

A responsive **Amazon Clone** website built using **HTML5 and Vanilla CSS**. This project recreates the look and layout of an e-commerce website inspired by Amazon.

## 🚀 Features

* 🏠 Amazon-style homepage
* 🔍 Search bar UI
* 📦 Product cards and product sections
* 🛍️ Shopping cart UI
* 👤 Account/Login UI
* 🧭 Navigation bar
* 📱 Responsive layout
* 🎨 Clean and modern design
* 🖼️ Product images and banners

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **Vanilla CSS** – Styling, layout and responsiveness

## 📂 Project Structure

```text
Amazon-Clone/

```

## 💻 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/amazon-clone.git
```

2. Open the project folder:

```bash
cd amazon-clone
```

3. Open `index.html` in your browser.

You can also use **VS Code + Live Server** to run the project.
